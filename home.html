📡
실시간 학생 모니터링
학생이 시뮬레이션을 조작하는 순간 교사 화면에 실시간으로 반영됩니다. 카드에서 조각 배치, 슬라이더 값, 그래프 결과를 한눈에 확인할 수 있어요.
🧩
드래그 퍼즐 시뮬레이션
수학 공식을 조각으로 분해해 직접 맞추는 방식으로 학습합니다. (a−b)², 합차공식 등 다양한 곱셈공식을 손으로 탐구할 수 있어요.
📊
확률·통계 실험
동전 던지기 반복 실험으로 표본 비율 분포를 시각화합니다. 큰 수의 법칙과 중심극한정리를 그래프로 직접 확인할 수 있어요.
👁
학생 화면 미리보기
교사가 카드를 클릭하면 해당 학생이 마지막으로 조작한 상태 그대로 시뮬레이션이 열립니다. 학생 기록에는 영향을 주지 않아요.
📁
시뮬레이션 관리
HTML 파일 업로드 또는 코드 붙여넣기로 시뮬레이션을 등록합니다. 폴더로 분류하고, 클래스를 열어 학생에게 링크를 공유하세요.
🔐
Google 계정 로그인
교사는 Google 계정으로 간편하게 로그인합니다. 아이디/비밀번호 방식도 지원합니다. 어느 기기에서나 같은 계정으로 접속할 수 있어요.

시뮬레이션 예시

현재 사용 가능한 시뮬레이션

드래그, 슬라이더, 반복 실험으로 수학 공식을 탐구합니다.

(a−b)²
곱셈공식
차의 제곱 시뮬레이션
5개의 정사각형·직사각형 조각을 드래그해 (a−b)²의 기하학적 의미를 탐구합니다. a, b 슬라이더로 변수 값을 바꾸며 수식 변화를 관찰해요.
드래그 퍼즐 슬라이더 기하학적 증명
(a+b)²
곱셈공식
합의 제곱 시뮬레이션
5조각 드래그로 (a+b)²= a²+2ab+b²를 시각적으로 증명합니다. 조각을 조합하며 공식의 의미를 직접 체득할 수 있어요.
드래그 퍼즐 정사각형 조합 기하학적 증명
a²−b²
곱셈공식
합차공식 시뮬레이션
L자 조합으로 (a+b)(a−b)=a²−b²를 시각화합니다. b(a−b) 조각 회전과 겹침 영역으로 공식의 의미를 탐구해요.
드래그 퍼즐 L자 조합 넓이 비교
P(X̄)
확률·통계
표본 비율 분포 시뮬레이션
동전 던지기 반복 실험으로 표본 비율의 분포를 시각화합니다. 큰 수의 법칙과 중심극한정리를 점그래프로 직접 확인할 수 있어요.
