1서비스 소개

수학 시뮬레이션 클래스룸은 교사가 만든 수학 시뮬레이션을 학생들이 실시간으로 조작하고, 교사는 모든 학생의 활동을 한 화면에서 모니터링할 수 있는 웹 기반 교육 플랫폼입니다.

주요 구성

페이지주소역할
교사 페이지teacher.html로그인, 시뮬레이션 관리, 학생 모니터링
학생 입장index.html클래스 코드 입력 후 시뮬레이션 참여
시뮬레이션student.html실제 시뮬레이션 화면 (직접 접속 불가)
참고

학생은 항상 교사가 공유한 링크 또는 클래스 코드로 접속해야 합니다. student.html에 직접 접속하면 오류가 나요.

2교사 계정 만들기

처음 사용하는 교사는 계정을 먼저 만들어야 합니다. 두 가지 방법이 있어요.

방법 A — Google 계정으로 가입 (추천)

1
교사 페이지 접속
아래 주소로 접속하세요.
https://mumaroma.github.io/sim-classroom/teacher.html
2
Google 계정으로 로그인 클릭
로그인 화면에서 [G Google 계정으로 로그인] 버튼을 클릭합니다.
3
Google 계정 선택
팝업에서 사용할 Google 계정을 선택하면 자동으로 로그인됩니다.

방법 B — 아이디/비밀번호로 가입

1
계정 만들기 클릭
로그인 화면 상단의 [처음 사용하시나요? 계정 만들기 →] 클릭
2
초대 코드 입력 (선택)
동료 교사에게 초대 코드를 받았다면 붙여넣고 [Supabase 자동 연결] 클릭. Supabase 정보가 자동으로 입력됩니다.
3
아이디 · 비밀번호 입력
사용할 아이디와 비밀번호(6자 이상)를 입력합니다.
4
계정 만들기 및 시작
[계정 만들기 및 시작] 버튼을 클릭하면 즉시 로그인됩니다.

3학생 입장 방법

방법 A — 교사가 공유한 링크로 접속 (가장 쉬움)

1
링크 클릭
교사가 카카오톡 등으로 공유한 링크를 클릭합니다.
2
이름 입력 후 시작
이름을 입력하고 [시작하기]를 누르면 바로 시뮬레이션이 열립니다.

방법 B — 클래스 코드로 접속

1
학생 입장 페이지 접속
https://mumaroma.github.io/sim-classroom/
2
클래스 코드 입력
교사에게 받은 6자리 코드를 입력하고 [입장하기] 클릭. 영문 대문자 + 숫자 조합이에요.
3
이름 입력
학생 이름을 입력하고 [시작하기] 클릭.
주의

코드 입력 방식은 교사가 공유한 링크를 통해 한 번 접속한 기기에서만 가능합니다. 처음이라면 반드시 링크로 접속해주세요.

4클래스 열기

1
시뮬레이션 탭 클릭
상단 탭에서 📚 시뮬레이션 탭을 클릭합니다.
2
원하는 시뮬레이션 선택
목록에서 수업에 사용할 시뮬레이션을 찾습니다. [👁 미리보기]로 미리 확인할 수 있어요.
3
▶ 클래스 열기 클릭
반 이름을 입력하고 확인하면 6자리 클래스 코드가 생성됩니다.
4
학생 링크 공유
🟢 진행 중 탭에서 [복사] 버튼으로 링크를 복사해 학생에게 전송합니다.
링크 종류

직접 링크: 이름만 입력하면 바로 시작. 카카오톡 전송 추천
입장 페이지 링크: 클래스 코드 입력 방식. QR코드로 변환 후 화면에 표시 추천

8자주 묻는 질문

학생 카드가 교사 화면에 안 나타나요▾
학생이 시뮬레이션에 접속한 직후 1~2초 안에 카드가 생깁니다. 그래도 안 나타나면 학생에게 페이지를 새로고침 해달라고 하세요. 교사 화면도 새로고침 해보세요.
시뮬레이션 목록이 "불러오는 중..."에서 멈춰요▾
Supabase 연결 문제일 수 있어요. 로그아웃 후 다시 로그인하거나, ⚙ Supabase 버튼에서 연결 정보를 확인해주세요. Supabase 프로젝트가 일시정지 상태라면 대시보드에서 Resume 해주세요.
학생 그래프 결과가 카드에 안 보여요▾
Canvas 기반 그래프는 학생이 실험을 실행해야 캡처됩니다. 학생이 [즉시 실행] 또는 [단계별 실행] 버튼을 누른 후 1~2초 기다리면 교사 카드에 그래프가 표시됩니다.
학생이 링크로 접속했는데 "시뮬레이션 ID가 없습니다"가 떠요▾
교사 페이지 진행 중 탭의 [복사] 버튼으로 복사한 링크를 공유해야 합니다. 주소창에서 직접 복사한 주소는 필요한 정보가 빠져 있을 수 있어요.
방학 후 접속하니 데이터가 없어요▾
Supabase 무료 플랜은 7일 미접속 시 프로젝트가 일시정지됩니다. supabase.com에서 프로젝트를 열고 [Resume project]를 클릭하면 데이터가 복구됩니다. Pro 플랜($25/월)은 자동 정지가 없습니다.
동료 교사도 같은 시스템을 쓰게 하려면?▾
교사 페이지 헤더의 [🔗 초대] 버튼을 클릭해 초대 코드를 복사, 공유하면 됩니다. 동료 교사가 계정 만들기 화면에서 초대 코드를 입력하면 같은 Supabase에 자동 연결됩니다.

9수업 활용 팁

수업 도입부

슬라이더로 a, b 값을 변화시키며 "어떤 패턴이 보이나요?"라고 질문해보세요. 학생들이 공식을 발견하는 과정을 교사 화면에서 실시간으로 관찰할 수 있습니다.

형성 평가

클래스가 끝난 후 카드 배치를 보며 "이 학생은 어떻게 조각을 배치했나요?"를 같이 살펴보세요. 학생 카드를 클릭하면 마지막 상태를 그대로 볼 수 있습니다.

QR코드 활용

입장 페이지 링크를 QR코드로 변환해 교실 화면에 띄우면 학생들이 스마트폰으로 바로 접속할 수 있어요. qr.io 또는 qrcode-monkey.com에서 무료로 만들 수 있습니다.
